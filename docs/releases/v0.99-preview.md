# AgentQT v0.99 Preview

> 非稳定预发布，请不要在关键生产项目中直接替代稳定版使用。

## Release Title

`AgentQT v0.99 Preview (feat / unstable)`

## Release Notes

这是一个功能预发布包，目标是提前验证新的桌面自动化链路，而不是提供长期稳定承诺。

### 重点变更

- 打包主程序切换为 `agent_qt_stream_quick.py`。
- 保留现有 Agent Qt 工作区、自动化、终端扩展指令和 Provider 调试链路。
- 合入最近一轮网页 Provider、`web_search` / `web_fetch` / `web_download`、后台终端日志和自动化执行相关修复。
- 增加本地对比与诊断脚本，便于继续做 AgentQT / Provider / agent2 的回归测试。

### 风险提示

- 这是 `feat` 包，不是稳定版。
- 自动化执行、终端扩展指令、网页 Provider 和下载链路最近改动较多，仍可能存在边缘回归。
- 如需保守使用，请继续保留 `v0.92` 一类已验证包作为回退版本。

### 建议发布物命名

- `AgentQT-macOS-v0.99-preview.dmg`
- `AgentQT-Windows-v0.99-preview.zip`

### 建议校验清单

发布前建议至少手工验证以下项目：

1. 应用可启动，工作区可正常打开。
2. 自动化插件可开启，Provider 状态正常。
3. `web_search`、`web_fetch`、`web_download` 可在一轮自动化中继续回传给模型。
4. Bash 命令执行后，不会异常停在“转圈不收尾”状态。
5. 打包产物实际入口确认为 `agent_qt_stream_quick.py`。
